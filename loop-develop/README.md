# Долговременные цели Pi Mobile

`current-todo/` — один активный, явно заказанный владельцем goal. `history/` — завершённые или явно отменённые цели с финальным результатом. Эти записи — рабочий план, а не стабильная документация: протокол, установка и принятые решения живут в `docs/`.

Новый агент начинает с корневого `AGENTS.md`, текущего кода, тестов и активного goal, а не с предположения, что старый план всё ещё соответствует runtime. Каждый milestone завершается работающим продуктом, проверками, визуальным сравнением и возможностью отката. Если работа становится слишком большой, следующий milestone оформляется отдельно; одновременно не запускать несколько конфликтующих миграций.

Запись в `current-todo/` **не запускает агент автоматически**, не разрешает перезапускать чужие Pi/Orca процессы и не даёт разрешения на push, релиз или отправку APK без актуальной авторизации пользователя. По прямому указанию выпускать обновления после правок действовать только после проверенного пользовательского изменения, не для одного goal-файла.
