# Pi Mobile — инструкция для агентов

Сначала читай `README.md`, `llms.txt`, `docs/architecture.md`, текущий код/тесты и `docs/protocol.md`. Для явно запрошенной долговременной миграции читай `loop-develop/README.md` и единственный активный `loop-develop/current-todo/001-todo.md`. Наличие goal-файла само по себе **не запускает** переписывание проекта. Точные владельцы существующих классов — `architecture/owners.json`, границы и сценарии — `architecture/capsules/README.md`.

Продукт — мобильное окно в **существующий** Pi в Orca, не отдельный агент. Никогда не завершай, не перезагружай и не подменяй работающий Pi ради теста; `/reload` допустим только когда владелец подтвердил, что сессия idle. Не запускай платные промпты для UI-тестов. Gateway слушает loopback, устройство подключается по HTTPS; не выводи токены, не клади их в APK и не ослабляй read-only inspection.

Дизайн, который уже работает, — baseline: нейтральная тема, единый Usage, компактная однострочная шапка чата, сообщения и сгруппированные инструменты, пропорциональные вложения/zoom, workflow drill-down, доступный composer. Миграция в Kotlin/Compose не разрешает менять пользовательскую иерархию наугад. Эталонные синтетические снимки и ограничения: `docs/ui-baseline/README.md`; проверяй вместе с интерактивными сценариями, узким экраном, крупным шрифтом и тёмной темой.

`nareshka-mono` — **только reference для принципов** agent-readable архитектуры (тонкий shell, владельцы-капсулы, публичные контракты, fail-closed checks), не источник кода и не объект правок. Делай последовательные вертикальные слайсы с собираемым Android в каждом, не big-bang rewrite. README/docs — стабильные факты и ограничения, `loop-develop/current-todo/` — активный goal.

Текущий gate: `npm run quality` (Node tests + fail-closed owner/import checks + контроль SHA256 эталонов); `cd android && ./gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest` с JDK17/Android SDK; ADB/UiAutomator для интерфейса. Перед релизом проверь versionCode, прежний signing certificate, APK SHA256, upgrade без удаления данных и правильный Telegram-чат. **Актуальная воля Billy от 5 октября 2026: до его утренней проверки НЕ публиковать обновление, не пушить, не деплоить и не отправлять APK/Telegram.** Все миграционные проверки локальны; текущие live Pi/Orca/gateway не трогать.
