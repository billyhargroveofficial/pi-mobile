# Иерархия каталога — 7 октября 2026

## Проверенные первичные источники

- Material 3 / Android: роли title/body/label разделяют назначение текста; Typography можно настраивать, применять все 15 стилей необязательно. https://developer.android.com/develop/ui/compose/designsystems/material3
- IBM Carbon: productive typography — компактный интерфейс для выполнения задач; expressive — преимущественно редакционные поверхности. Токены Carbon рассчитаны на IBM Plex, это не норматив Android-sp. https://carbondesignsystem.com/elements/typography/overview/
- NN/G: важность передают размер, вес, контраст, расположение и интервалы. Близость связывает элементы; межгрупповой интервал должен отличаться от внутригруппового. https://www.nngroup.com/articles/principles-visual-design/ и https://www.nngroup.com/articles/gestalt-proximity/
- Android accessibility: рекомендуемая цель касания ≥48×48dp; видимый знак может быть меньше. Для небольшого обычного текста нужен контраст ≥4.5:1. https://developer.android.com/guide/topics/ui/accessibility/apps и https://developer.android.com/develop/ui/compose/accessibility/api-defaults
- OpenAI: неизменённый официальный asset, clearspace, связь с услугами OpenAI, без впечатления endorsement. https://openai.com/brand/ — происхождение SVG и native vector описано в [ui-assets/openai](ui-assets/openai/README.md).

Источники проверены онлайн. Ограничения чтения: страница Material applying-type непосредственно отдала JS-заглушку; рекомендации по табличным цифрам доступны в поисковом индексе. NN/G hierarchy-definition не загрузилась, использована официальная principles-visual-design. Полный OpenAI brand portal требует авторизации; публичная страница и официальный архив логотипов доступны. Это не заключение о безусловной лицензии на любое использование марки.

## Применение — продуктовые решения, не обязательные числа из источников

| Роль | Реализация |
|---|---|
| Название чата — основной объект выбора | 16sp regular / 24sp, основной цвет, отступ от группы 16dp |
| Workspace — группирующий контекст | 12sp medium / 16sp, вторичный цвет, явный префикс Workspace |
| Заголовок раздела | 14sp medium / 20sp |
| Хост — идентичность подключения | 18sp medium / 24sp, одна строка; статус слева, интервал 8dp |
| Usage — справочная информация | 12sp regular / 16sp, табличные цифры; акцент только на проценте и тонкой шкале |
| Вторичная метаинформация | 11sp regular / 14sp |

Не делать всё жирным и одинаково крупным. Не превращать workspace или лимиты в более заметный объект, чем сами чаты. Близость соединяет статус с хостом; refresh/settings — отдельная правая группа: одинаковые цели48dp и glyph-box22dp, интервал4dp. Мелкая статусная иконка не является третьей кнопкой.

Usage — три информационные строки ≥28dp как один доступный clickable-блок ≥48dp, не три мелкие цели. Все квоты доступны в единой прокручиваемой панели. Недоступные и кешированные данные обозначены словами; отсутствие данных не заменяется нулём. Процент доступен текстом, а не только цветом. Обычный блок ограничен тестом ≤108dp; при увеличении шрифта строки честно переносятся, размер текста не уменьшается принудительно.

Проверки и точные даты прогонов: [ui-redesign-20261007.md](ui-redesign-20261007.md). Последняя перестановка шапки проверена в light1×, narrow light2× и narrow dark1.3×, включая измерение целей касания и интервалов. Это проверка эмулятора, не физического телефона.
