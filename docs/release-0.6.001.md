# Pi Mobile 0.6.001

- Новый единый блок Usage: наиболее израсходованная квота, все окна и сбросы в подробностях, явное отсутствие данных.
- Настройки: разделённые строки обновления и цвета сообщений, без слипания кнопок.
- Диктовка до10 минут с реальной волной микрофона. Приватный временный файл, бинарная загрузка, локальное распознавание ограниченными сегментами. Текст остаётся черновиком.
- В шапке чата — модель, effort и tier активного запроса. Выбор Standard / ⚡ Fast для поддерживаемых Responses-провайдеров, только в текущей сессии. Запрошенный Fast отличается от подтверждённого провайдером.

## Установка

Установить APK поверх 0.6.000 либо Settings → Check for updates. versionCode8, прежний сертификат; подключение сохраняется. Это персональная debug-сборка, не Play Store.

Gateway также требует обновления для длинной диктовки. Для tier требуется новое расширение: существующие Pi обновлять через `/reload` только после завершения работы. Работающие сессии автоматически не перезагружаются.

## Проверки и ограничения

53 серверных теста, 127 JVM-тестов, 35 Android UI-тестов проходят. Экраны просмотрены в API35-эмуляторе; выбор tier дополнительно проверен на360dp с шрифтом1.3×. Реальный локальный движок успешно распознал75-секундный тестовый файл.

Live-подтверждение priority на аккаунте провайдера не проверялось платным запросом; доступность зависит от провайдера. Десятиминутная непрерывная запись физического микрофона не прогонялась. Отдельная визуализация workflows/субагентов пока не реализована.
