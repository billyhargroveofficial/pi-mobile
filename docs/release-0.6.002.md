# Pi Mobile 0.6.002

- Статус, модель, effort и доступный tier собраны в одну строку под названием чата. Неизвестный tier не занимает место; длинная строка прокручивается горизонтально.
- Исправлен дубль сообщения с изображением: сверка серверного ответа учитывает служебную строку размеров, добавленную Pi. Число изображений учитывается, сопоставление остаётся один-к-одному.
- Миниатюры сохраняют пропорции, без широких пустых полей; уменьшены скругления.
- Исправлено открытие изображения из обёрнутого контекста интерфейса. По нажатию — полный экран, увеличение двумя пальцами и двойным тапом.

Установить поверх предыдущей версии или Settings → Check for updates. versionCode9, прежняя подпись и настройки подключения. Персональная debug-сборка.

Проверки: 129 JVM-тестов и 36 UI-тестов прошли на API35. Добавлены регрессионные тесты дубля, пропорций миниатюры и открытия через реальный адаптер с обёрнутым контекстом. UI-тест проверяет изменение масштаба, а не только наличие viewer. Шапка просмотрена на скриншоте эмулятора.

Изменения Android-only; перезапуск gateway и Pi не требуется.
