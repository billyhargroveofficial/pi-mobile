# Проверка 0.2 — 5 октября 2026

## Объём

Редизайн выполнен основным агентом, без делегирования DeepSeek. После обратной связи убраны рекламные заголовки, статус перенесён наверх, карточки и чат уплотнены. Добавлены только запрошенные функции: сворачиваемые live tool calls, увеличение изображений, управление моделью и effort текущей сессии.

## Проверено

- `npm test`: **7/7 PASS**. Включает валидацию configure, недоступные модели/effort, запрет изменений во время задачи, отсутствие частичного переключения на неверной комбинации, dedupe, стабильный ID tool call на start/update/end, аргументы и кумулятивный вывод.
- Android unit tests: **99/99 PASS**; `assembleDebug`, `assembleDebugAndroidTest` успешны.
- Android instrumentation: **8/8 PASS** на настоящем AVD API35: Material-компоненты, эксклюзивные режимы follow-up/steer, touch-target48dp и границы экрана, реальная клавиатура, bottom sheet подключения, сохранение раскрытого инструмента во время стриминга, полноэкранное изображение и pinch, модель/effort отправляются только по «Применить».
- UI-тесты прошли на узком360dp экране с fontScale1.3 и тёмной темой. Финальная сборка повторно проверена на стандартном Pixel7,420dpi, светлой теме.
- В тесте IME ожидание системной клавиатуры сначала оказалось слишком ранним; исправлен сам test synchronization с обязательной проверкой видимости IME, а не отключением assertion.

## Настоящий Pi через публичный HTTPS/WSS

Создана отдельная сессия `Pi Mobile UI verification`, ID `01a10bfd-944a-71ca-adaa-ccb821342665`, **обычный Pi с пользовательскими плагинами**. Рабочие сессии не изменялись.

- Пришли11 доступных моделей из registry. Для GPT-6 Sol возвращены off/minimal/low/medium/high/xhigh/max, для DeepSeek — его собственные уровни. Ключи доступа не передавались.
- Через реальный Android UI изменён effort minimal→high. Сервер вернул подтверждённый high в configuration.
- Через тот же WSS command path текущая модель временно переключена на `openai-codex/gpt-5.3-codex-spark`, подтверждена снимком, затем возвращена `openai-codex/gpt-6-sol`.
- Безопасный bash напечатал три строки прогресса с паузами; получено4 live-обновления инструмента. Финальный результат сохранил тот же ID.
- Инструмент read вернул PNG; в Android раскрыт read, картинка открыта нажатием на весь экран.
- Получен финальный ответ `UI_FEATURES_OK`. Провайдер сначала вернул overload; встроенный retry Pi завершил запрос.
- Настройки тестового процесса восстановлены после smoke-проверки. Глобальные defaults и другие диалоги не менялись.

Повторение live-проверки: `node scripts/ui-feature-smoke.mjs <dedicated-test-session-id>`. Скрипт отказывается работать с чужим/неактивным диалогом.
