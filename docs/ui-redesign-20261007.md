## Current design contract

1. Neutral light/dark canvas; blue user bubbles and user-selected color remain. No UI outlines, outlined fields/actions or card dividers across catalog, history, Usage, settings, model/effort/tier, dictation, updates and orchestration. Filled fields retain labels and transparent indicators. Markdown document rules are semantic content, not UI borders.
2. Assistant answers are unboxed documents. Tool calls are bare chronological segments between messages, not bubbles/cards. Header contains only the latest actual tool name (vertical roller when it changes) and count, no icon/Tools/Running/blanket Error label or rectangular press indication. Individual failures retain their glyph/semantics. Independent disclosure and bounded inner scrolling remain.
3. Transcript occupies the full screen behind top and bottom islands. Measured overlay padding makes first/last content reachable; light/dark gradients fade content beneath controls. Compose owns chat system/IME insets; other screens retain their existing inset owner.
4. Full-width writing row above four 48dp actions. Available line capacity adapts to keyboard, large type, active-work dock and Queue without changing IME mode. Draft/caret ownership, explicitly hidden keyboard and reduced-motion behavior remain. Empty-state decoration yields to keyboard; jump-to-latest only scrolls locally.
5. Active-only work dock: actual live workflow entries are separate from standalone agents. Workflow-linked agents are not duplicated. Completed/paused/unknown/saved data never claims to be live. Completed history remains reachable from the header. Under IME, workflow/agent entries form a compact horizontally scrollable dock.
6. Workflow drill-down groups actual phases → assigned agents; unassigned agents are explicit. Tools, tokens and elapsed time come from actual records, never fabricated zeros/progress or guessed phase assignment. Agent inspection remains read-only, including running states.
7. Queue above input shows this app/device's Follow Up messages submitted while Pi was known busy. It is a receipt projection, not a second scheduler or a global Pi queue. Expand/collapse is bounded; Sending/Queued/Unknown states are honest. ACK means accepted, not consumed. A new matching canonical user echo consumes one item; old identical messages and repeated snapshots cannot consume another. Restore is explicitly `Last known`, without automatic resend. No invented cancel/reorder API.
8. `read` is outside ONLY the latest user message. A newer unacknowledged submission hides the old receipt; ACK/remote echo permits the newest receipt, never implies task completion. Older failed/uncertain receipt retry/restore stays available. The older-messages banner is removed from main chat; history/truncation metadata and pagination are unchanged. Preserve manual model/effort/tier dismissal, no Toast/Snackbar, and transcription spinner/draft-only behavior. No drawer.
9. Plain compact catalog rows: no chat icon/card/provider subtitle or idle/running text/dot, only a spinner for actual running sessions. Workspace is a distinct muted 12sp group label; chat titles are 16sp regular and indented. Idle swipe paints no destructive underlay, including rounded anti-aliased corners.
10. Main title is the actual host, not Pi Mobile. Connection icon/spinner is LEFT of the host with an 8dp gap and spoken state; refresh/settings form a separate right-hand group with equal48dp targets/22dp glyph boxes and a4dp gap. CatalogSession keeps confirmed/attempted endpoint distinct from the unsubmitted settings draft; displayed title excludes credentials/path/query and supports ports/IPv6.
11. Three compact Usage information rows form one accessible action to unified scrollable details, retaining all quotas and honest cached/unavailable states. Numeric accents are restrained; OpenAI uses the untouched official black/white path and original padded viewport. Settings uses horizontal slide navigation and preserves catalog scroll/drafts on return. Usage skips the half-expanded detour so Back dismisses it at large font too.
12. Composer has no bottom shadow. Inline-code URLs have no misleading gray selection background; real native selection and fenced-code background remain. Quick effort track is33dp (1.5×), without a pending/waiting line; rejection appears above controls. Pending ACK still disables duplicate changes; panel dismissal remains manual.
