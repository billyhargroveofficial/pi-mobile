# Pi Mobile 0.6.003 — Workflows & agents

- В чате появился вход **Orchestration** с количеством workflow, агентов и реально работающих задач.
- Workflow раскрываются в этапы и список агентов: очередные, работающие, завершённые, остановленные и с ошибкой показываются отдельно. Модель, effort, время и выходные токены — из наблюдаемого состояния, не выдуманный процент.
- По нажатию на агента открывается его внутренний диалог: задача, промежуточные текстовые сообщения, инструменты и ответ. Есть переход к вложенным агентам, ручная догрузка старых страниц. Экран только для чтения: отправка, остановка и перезапуск недоступны.
- Завершённые фрагменты приватно сохраняются gateway. Если наблюдатель не подключён, показывается только доступная история с неопределённым состоянием, без выдачи старой работы за live-прогресс. Служебные system/thinking-блоки исключены.
- Проверены API35-эмулятор и узкий экран с1.3× шрифтом. 64 серверных, 131 JVM и40 Android UI-тестов проходят. В серверных тестах также проверены авторизация, запрет browser Origin, разграничение сессий, защита от path traversal/symlink, накопление истории и внутренний read-only путь.

## Установка и ограничения

APK versionCode10 устанавливается поверх0.6.002; подпись сохранена. Для новых API требуется обновлённый gateway. На Mac установлен ограниченный read-only observer для `@tintinweb/pi-subagents` **0.19.0**; после обновления зависимости его совместимость нужно перепроверить. Работающие Pi-сессии **не перезагружались**. Новые сессии подхватят наблюдатель, а существующие — лишь после `/reload` в состоянии idle; на других хостах см. `docs/setup.md`.

Live-скриншоты подтверждены синтетическими записями и транспортными тестами. Реальный workflow, запущенный после безопасного reload на пользовательском Pi, в этой проверке не выполнялся: существующих агентов не прерывали и не запускали тестовых платных подзадач. Старые workflow без сохранённого live-снимка могут быть недоступны целиком; чтение отдельных `.output` логов не восстанавливает фазы и workflow-детей. Часть старых технических ошибок остаётся на русском.
