# Pi Mobile 0.6.000

Preview APK для установки поверх0.5.1; настройки и подпись сохранены. Следующие версии:0.6.001,0.6.002 и далее.

## Включено

- Обновления из приложения: автоматическая/ручная проверка GitHub, подтверждаемая загрузка, SHA256 и сертификат, системный установщик Android. Эту первую версию с обновлятором установить вручную.
- Приватный кеш диалогов и прокрутки, условная синхронизация только изменений с обновлённым gateway. Старые gateway продолжают отдавать полные снимки.
- Открытые промежуточные сообщения, анимированное сворачивание только инструментов без стрелки, индикаторы загрузки.
- Нейтральная тёмная/светлая палитра и выбор цвета своих сообщений.
- Реальные лимиты Codex/Cursor/Grok из локальной Orca без передачи токенов. Недоступные значения отмечены явно.
- Подготовка вложений блокирует преждевременную отправку. Чтение истории больше не расходует бюджет prompt/abort.

## Проверки

48 серверных,125 JVM и31 Android UI-тест прошли. APK установлен поверх предыдущей версии на API35 ARM64; сертификат совпадает с0.5.1.

## Ограничения

Отдельные карточки workflows/субагентов ещё не вошли; английская локализация технических сообщений не завершена. Полная цепочка следующего обновления из GitHub на физическом телефоне не проверена; Android всегда требует подтверждение установки. Персональная debug-signed preview-сборка, не Play Store.
